# Contributing

Use Node.js 22 or newer. Run `npm start` for local development, `npm test` for logic tests and `npm run check` for syntax checks. No build step is required.

Keep camera frames on-device. Add focused tests for changes to gesture or eye-closure logic. Manually verify affected camera, recording and responsive UI behavior in a supported desktop browser. Describe the change and verification in pull requests. Do not commit camera recordings, credentials or private reference images.
